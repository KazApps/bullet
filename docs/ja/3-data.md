# 学習データ

`bullet-utils` を `cargo b -r --package bullet-utils` でコンパイルし、`./target/release/bullet-utils[.exe] help` を実行して使用方法を確認してください。
これらのユーティリティは、特定のデータ型ファイルをシャッフルおよびインターリーブするために使用できます。

## 一般的なワークフロー

1. データを何らかの形式で保存します（binpack のような形式を強く推奨します）。
2. 必要に応じて、データファイルをこの形式から `Trainer` が取り込めるデータ形式に変換します。
3. 変換された個々のファイルをシャッフルします。
4. シャッフルされたファイルをインターリーブします。

## 提供されるデータ型

データ形式の仕様は、[`bulletformat`](https://github.com/jw1912/bulletformat) クレートにあります。

提供される各バイナリデータ型は `from_raw` を実装しており、エンジンが Rust で記述されている場合（または FFI を気にしない場合）は、データ生成での使用をお勧めします。

一般的に、以下で説明する方法で必要な形式でデータを取得する以外は、カスタム入力を実行する場合を除き、それらについて考える必要はありません。

### ChessBoard (別名 "bulletformat")

このデータ型は `DirectSequentialDataLoader` でロードできます。

これはチェスのトレーニングの標準的なデータ形式であり、固定の 32 バイトのレコードで、カスタム情報を保存するための予備のバイトがいくつかあります。
手番側（レコードは手番側を基準に保存されます）、ハーフムーブカウンター、キャスリング権などの情報は破棄されます。

`bullet-utils` を使用して、[Marlinformat](https://github.com/jnlt3/marlinflow) またはテキスト形式のファイルから変換できます。

テキスト形式:
- 各行は `<FEN> | <score> | <result>` の形式です。
- `score` は白を基準とし、センチポーン単位です。
- `result` は白を基準とし、勝利の場合は `1.0`、引き分けの場合は `0.5`、敗北の場合は `0.0` の形式です。

### Stockfish & Monty Binpacks

これらの型は、それぞれ `SfBinpackLoader` および `MontyBinpackLoader` でロードできます。
`bullet-utils` には、Monty binpack をインターリーブするためのユーティリティがあります。
Stockfish には、独自の binpack 形式をインターリーブするためのツールが含まれています。
